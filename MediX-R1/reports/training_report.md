# 医疗 LoRA 训练结果与分析：247 道项目留出测试

2026-09-06，Qwen3.5-2B，A–F 适配器。当前结果统一来自本次项目 test 集评测。

**扩测支持的判断是：FFN 并未普遍损害知识答题；加入知识数据后的净收益仍不明确；加入上下文数据后，解释对材料的忠实程度出现了更值得处理的退步。不能把三个现象统一解释成“FFN 把医疗知识破坏了”。**

本轮完成 247 道项目留出题、944 份生成回答，并进行 teacher-forcing loss 探针、分段 loss 检查和初始化实验。本轮没有执行新训练；以下成绩只来自测试题，训练集 loss 单列，不计入测试成绩。

## 这次如何验证

- 知识题 150 道：解剖、生化、微生物、病理、药理、生理各 25 道，比较 A/B/C/D 及 D 的 FFN LoRA 推理缩放减半。
- 上下文题 97 道：比较 E/F，包含 yes 52、no 34、maybe 11 道。
- 数据来自已有 `knowledge_experiments_v1/test.jsonl`，与原训练集、验证集在 source_id 和 source_group 上均无重叠。与已检查的 3,537 个历史 samples/questions 文件也没有题目 ID 重叠；没有宣称排除了所有历史文件形式或基座预训练中的出现。
- 全部使用同一题目分组、batch=4、greedy、原生思考、总预算 2,048 token、思考预算 1,792 token。没有根据中途表现换题或调整缩放。
- 匿名评分器为 gpt-5.6-sol。同题相同完整输出共用评分。答案和解释分别评 0/1/2；联合分为 `50 × mean(min(答案分, 解释分))`。所有分数是评分归一化结果，不能当作严格正确率。
- 主指标为答案分；解释分和联合分单独报告。答案分和解释分分别为 `50 × mean(0/1/2 评分)`；“最终答案满分数”是答案获 2 分的题数。所有对照使用相同规则。
- 基座、VQA 和病例没有参加本轮测试，不给出它们的分数，也不计算四任务综合分或宣称最佳配方。

## 数据收集、整理与隔离

本轮没有新下载数据，也没有合成评测题；取项目已有 test 集中全部知识和上下文样本，在生成前冻结，共 247 题。

| 任务 | 上游来源 | 此前整理与划分 | 本轮测试 |
| --- | --- | --- | --- |
| 知识 | openlifescienceai/medmcqa | 六学科 2,000 道候选经助手审阅整理，保留 1,493 道；每学科固定随机划出验证 25、测试 25，剩余 1,193 道用于训练 | 150 道，每科 25 |
| 上下文 | qiaojin/PubMedQA，pqa_labeled | 1,000 道标注题按 yes/no/maybe 分层，以 seed=42 分为 800/100/100；此前推理格式加工隔离了 3 条测试样本 | 97 道：yes 52、no 34、maybe 11 |

知识题整理为自然语言问答，必要时保留选项信息；解释包含模型生成、助手审阅和改写，不是全部由医学专家新标注。PubMedQA 保留研究上下文、问题、原始标签与长答案。两类测试都属于项目自行划分的同源留出集，不是官方测试榜单划分。

训练文件追溯确认：C/D/E/F 的配方哈希匹配训练记录，每组 1,193 条知识样本的解释和最终答案均与审阅后的自然语言版本逐条一致；实际训练标签同时监督解释与答案。没有发现只使用原始短答案或漏掉大模型改写的问题。“最终答案中位数 2 词”仅描述 final 字段，不代表完整监督长度，也不能据此认定模型只学习了形式。

模型自由生成时只输入问题、研究上下文和统一系统提示，不输入参考答案或参考解释。参考文本只用于评分或单独的条件损失计算。按 source_id 和 source_group 复核，与训练和验证的交集均为 0；尚未完成全面语义近重复排查，也不能排除基座预训练包含公开题目。

另抽取的知识训练题 120 道、上下文训练题 96 道仅用于 loss 探针。它们不出现在本报告的测试分数分母中。

各配方从相同 Qwen3.5-2B 基座分别训练，E/F 的“再加”指配方增项，不是从 D/E 的适配器顺次续训。LoRA rank=8、alpha=16、dropout=0.05，学习率 5e-5，有效 batch=4，训练 1 epoch、seed=42，视觉编码器冻结。

| E | VQA + 知识 + 病例 | Attention+FFN | 4,653 | 1,164 |

## FFN LoRA：尚无普遍损害知识答题的证据

知识测试上，B−A 答案分为 +1.33，D−C 为 +3.67，两个配对区间均跨零。当前既不能证明 FFN 稳定有益，也不能证明它普遍导致下降；这一判断只适用于本轮已测的知识任务。

FFN 扩展改变的是整个共同训练过程。可训练参数由 3,096,576 增至 7,815,168，约 2.52 倍；它并不意味着有效学习率自动扩大 2.52 倍。最终权重检查显示，B 与 A、D 与 C 的 Attention 更新本身也不同，因此不能把 B 理解为“原封不动的 A 上再加一块 FFN”。

本轮初始化实验采用真实模块顺序和矩阵尺寸、相同 seed=42、安装中的 PEFT，仅进行初始化，不做模型前向或训练：加入 FFN 后，78 个共有 Attention LoRA A 矩阵里，只有 3 个相同、75 个不同。这验证了全局随机种子不足以固定共有模块的初始化。它不是历史 RNG 状态的完整重建，也没有量化这一因素造成多少分差。

从模型结构上，FFN 参与特征变换和输出分布形成；“存储知识”是帮助理解的类比，不是一个只会追加新事实的独立数据库。LoRA 添加的低秩更新会改变原有输入的计算结果。[Geva 等人的 FFN 研究](https://aclanthology.org/2021.emnlp-main.446/)支持这种功能理解，但不是这次训练退步的直接证据。

**当前不能确认的原因包括：FFN 学习率过大、rank 不合适、梯度冲突或灾难性遗忘。** 新的 D 缩放减半实验只有 +2 分且区间跨零，尚不足以确定通用缩放方案，更不能直接推导重新训练时学习率减半会有同样效果。

## 为什么加知识后没有获得稳定收益

补充诊断已逐题检查输出形式，并完成 900 次解释前缀干预前向。新增知识使答案中位长度从 10 词降至 2 词，但改善与退步题都变短；低答案 NLL 强烈依赖标准解释。详见[短回答形式与条件损失诊断](<output_style.md>)。

后续已完成 [T0–T3 形式与关系解释的开发集续训对照](<format_factorial.md>)：同一 C 起点、每组 191 道知识题与 192 道 VQA 回放、192 步；在 150 道知识开发题与 16 张开发图像上完成 830 份输出和匿名评分。T1/T3 完整句比例为 100%/99.3%，T0 为 4.0%，证明这种形式能够学会；T1 答案分差仅 +0.67，T2 为 +4.00，T3 为 +2.00，配对区间均跨零。T2 的解释分没有同步改善，四组续训在同样两道 VQA 题上退步，因此尚无稳定性能提升结论。这批开发结果与本文 247 道 test 成绩分别保留，不混入测试表。

**知识数据确实改变了模型对监督文本的拟合，但没有转换为明确的自由答题净收益。** C−A 的答案分比较中，12 题改善、18 题退步；D−B 中，15 题改善、15 题退步，分值变化幅度不同。新增正确回答与局部回退同时存在。

新知识题的学科结果也不是一致下降：例如 C−A 的答案分在病理为 +6、微生物 +2，生化 -12、生理 -10。每学科仅 25 题，这些是异质性的线索，不能据此确立学科策略。

为了检查“是不是没学进去”，本轮固定抽取知识训练题 120 道（每学科 20 道）和上下文训练题 96 道，与全部新留出题一起计算标准监督的 loss。

| 任务与模型 | 训练题整体 NLL | 留出题整体 NLL | 留出题标准答案文本 token NLL |
| --- | ---: | ---: | ---: |
| 知识 A | 1.4291 | 1.4304 | 1.0887 |
| 知识 B | 1.3460 | 1.3449 | 1.2153 |
| 知识 C | 0.9521 | 0.9530 | 0.2911 |
| 知识 D | 0.8850 | 0.9317 | 0.2809 |
| 知识 D，FFN 0.5 | 0.9430 | 0.9642 | 0.3195 |
| 上下文 E | 1.4583 | 1.4298 | 1.3177 |
| 上下文 F | 1.1904 | 1.2151 | 1.0255 |

数值越低表示越贴近给定参考文本。这里按题平均；逐 token 加权的结果也保留在原始文件。答案文本 NLL 精确定位到答案 token，排除了答案外的换行和 EOS，但其条件中包含标准解释。**它不能独立证明模型在闭卷条件下掌握了相应知识。**

这组实验揭示了两个重要区别：

1. C/D 的训练和留出 NLL 都下降，不能直接归为“只记住训练集、留出整体恶化”的典型过拟合。它们学到了监督分布中的某些规律，但正确性、知识调用和泛化收益还需自由生成评测。
2. B 相比 A，留出整体 NLL 从 1.4304 降至 1.3449，答案条件 NLL 却从 1.0887 升至 1.2153。整体 loss 的改善可以掩盖不同输出部分的相反变化，不能替代下游验收。

训练数据中的解释 token 很多：知识约 82%，VQA 约 77%（以解释与答案文本 token 计）。解释平均长度分别约 33.4 和 33.1 token，因此“知识解释短”本身也不足以解释 C 相对 A 的变化。本轮没有对解释长度做受控训练干预，不能单凭这些统计决定统一加长解释。

此外，加数据同时增加了训练预算：A/B 432 步，C/D 730 步，E 1,164 步，F 1,355 步；warmup 和 cosine 调度也随之改变。共有样本的数量、问题、解释和答案保持一致，但任务占比和更新轨迹改变了。现有对照不能把数据内容的作用与额外训练步数完全分开。

## 上下文下降：更明确的问题在证据忠实度

E→F 的最终答案分仅变化 -0.52，但解释与联合分均下降约 9.79。按联合分，15 题改善、35 题退步；35 个退步样本中，23 个最终答案仍满分。评分器在这 35 条中将 28 条标为材料误读，9 条标为无依据推断，标签可重叠。

直接阅读原文后，能确认以下实质问题：

- `pubmedqa-18182265`：材料说 23 例中 19 例仅靠 T2 图像即可检出，加入 DW 后在其余 4 例中补检 3 例。F 写成“19/23 例原方法不足，新增方法检出了其余癌症”。它颠倒了关键结果，最后的 Yes 却仍正确。
- `pubmedqa-20971618`：材料的 913 人是全体有资料儿童，其中 132 人有 AD；45.1%、19.7%是不同感染的比例。F 把 913 人都写成 AD 儿童，并将两个比例改成 AD 与非 AD 的组间比较。
- `pubmedqa-27394685`：材料报告观察者间 ICC=0.89、符合“优秀一致性”；F 写成“一致性很差”，又把缺损程度的相关性改成病变存在性的预测关系。

F 的解释中位长度为 50 个英文空白分词，E 为 41；平均总生成 token 为 102.03 对 78.05。**更符合现有证据的解释是：训练使 F 更贴近研究总结的生成方式，但自由生成时，对数字、对象、范围及比较关系的绑定没有同步变稳，细节展开增加了错误机会。** 这是对观察结果的机制解释，不是已经由独立训练干预证明的唯一原因。

标准文本 loss 下降与此并不矛盾。Teacher forcing 使用正确前文，实际生成则使用模型自己的前文；早期误读可能继续影响后文。这个训练与推理条件的区别在[经典序列预测研究](https://arxiv.org/abs/1506.03099)中有明确讨论，但本轮没有把损失下降与错误累积之间的因果贡献量化。

部分轻微扣分涉及因果措辞或范围边界，仍有判分不确定性；本轮没有逐条独立复核全部 944 份回答。明确的数值、组别反转说明，观察到的问题也并非仅由措辞偏好造成。本轮没有完成全量训练监督的医学复核，因此不能将这类生成错误直接归因于训练数据普遍错误。

## 接下来最值得做的受控验证

优先处理上下文证据关系：围绕相同研究主题构造改变分母、组别、结果方向和显著性的成对样本，要求结论随证据改变，并保留原文证据位置；随后用原数据与修复数据做相同步数、相同初始化的训练对照。这比仅增加同类摘要或统一拉长解释更直接地针对已观察的失败。

FFN 的下一轮训练对照应显式对齐共有 Attention 初始权重，固定数据与优化预算，比较原 FFN 学习率和更小 FFN 学习率，并用多个训练种子复验。研究“加数据”时还应补上原数据延长训练的对照，以区分额外计算和任务配方的影响。

本次 test 已用于诊断，后续选择参数或修复样本时应回到开发集，最终确认另用未参与选择的数据。本轮没有扩测 VQA 与病例，不能重排完整四任务综合榜，也没有定位某个事实唯一存储在哪一类层里。
