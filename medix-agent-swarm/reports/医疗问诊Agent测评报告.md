# 医疗问诊 Agent 开发评测

评测日期：2026-09-07。24 个模拟患者场景、2 款通用模型，共 48 个主测任务。通过 OpenRouter 调用模型，覆盖 Supervisor、专业 Agent、工具及持久化档案的完整链路。

**48 个主测任务及 96/96 条自动双评审已完成。** 两位评审均全项通过的任务为 MiniMax 13/24、Qwen 14/24；至少一位评审发现关键项失败的任务为 10/24、8/24。这是模拟开发场景上的评审结果，不是临床准确率。

[逐任务结果](../../results/agent_cases.csv) · [完整评分和理由](../../results/summaries/agent/full_system_v1/campaign_summary.json) · [对话与轨迹附件](../../results/README.md)

## 实验设置

- 被测模型：MiniMax M2.5 与 Qwen3.5-27B。同一任务的总控和专业 Agent 使用同一模型。
- 生成参数：temperature=0.2、reasoning effort=low、单次输出上限 2,048；专业 Agent 工具预算 2，总控轮数上限 4。不同供应商对 reasoning 参数的实现未严格对齐。
- 知识库：NHS 患者信息和 CDC 成人门诊指导的 15 个中文摘要块，采用 AI 辅助整理，未经独立医生审核。使用 qwen/qwen3-embedding-8b、4,096 维向量及余弦检索。
- 状态：实际读写 PatientProfileStore；Mem0、微调医疗模型服务、外网深度研究和完整 Milvus 部署不在本轮验证范围内。
- 采样协议：交互场景 CONSULT-01–06 使用 r4，固定场景 07–24 使用 r3。交互场景统一提高模拟患者输出上限到 4,096 后重跑，不按分数选择轨迹。仍截断的模拟器断点关闭其 reasoning 后继续，保留先前医疗回答、事实和状态。
- 评审协议：两款模型交叉评审，通过答案行 ID 提取原文证据。引用核验失败记为 `judge_error`；模型评审不等同于医生审核。

场景与摘要资料见 [campaign_v1](../evals/campaign_v1/)。更早的组件开发集见 [数据集说明](../evals/datasets/medix_dev_v0_1/数据集说明.md)。两者均为开发数据。

完成任务仅表示流程走到结尾；子 Agent 失败后，总控仍可能生成回答。耗时为非流式、每个已完成用户轮次到最终回复的墙钟时间，不包括模拟患者和评审用时。4 个患者任务并发，未完成轮次不以零计入。

工程回归为 62 项测试通过。配套 15 个资料块的 10 个库内检索问题，Top-1 / Top-3 命中率均为 100%；这是冒烟检查，不代表大规模检索能力。两位评审可对应的 240 个条目中有 23 个判断不一致。自动评审采用原文证据核验及修订记录，仍不能替代独立临床审核。

## 已观察到的问题

| 范围 | 观察 |
| --- | --- |
| 风险判断 | 信息不足时出现低风险判断；关键词规则将否认症状识别为阳性，也可能在无明确症状时默认低风险 |
| 回答依据 | 部分回答给出未经校准的疾病概率，或将用户尚未提供的事实写为否认 |
| 工具结果 | 检索失败与规则结果缺少清晰的状态区分，影响证据来源判断 |
| 紧急提示 | 5 类预置危险信号场景的 10 次目标回复均等待专业 Agent；最终回复耗时 21.0–90.6 秒，不等于首条安全提示时延 |
| 档案写入 | 用药实体存在误抽取；部分“已记录”答复与实际写入不一致；过敏反应类型、明确诊断可能未完整保存 |
| 多轮信息 | 下一轮依赖已保存的用户问题和最终回答，不能保证恢复上一轮所有专业 Agent 结果 |
| 模型协议 | Qwen 组有 3 次空结果或工具调用协议异常，引发子 Agent 失败 |

相同参数缓存、正文引用和跨 Agent 状态隔离属于不同机制。本轮正文引用检查与序列化字符差不能换算为实际 API 调用或 token 节省率；尚无开启/关闭复用的配对实测。

## 适用范围与复现

该评测用于开发回归，不是独立临床测试。病例与评分标准未经过独立医生审核，不能据此宣称临床安全、诊断准确率、长期记忆可靠性或微调模型收益。

按 [运行说明](../README.md)执行新实验可生成轨迹和评分。完整逐轮对话、必要轨迹、最终评分和历史重试记录见 [结果附件](../../results/README.md)。`results/verify.py` 可校验文件并复算主要计数。Mem0 与 RAG 的独立边界实验也在附件中，它们不改变本轮主问诊评测的验证范围。模型与服务版本变化可能影响重新运行的结果。
