# 跨会话记忆：原话回查与事件时间保留

长期记忆抽取会压缩信息，容易混淆事件发生、用户咨询与系统保存的时间。当前实现为新写入的记忆附带最多 **4,000 个字符的用户原话**，标记截断，并要求抽取和回答阶段保留事件的时间归属；未知日期保持未知，已有记忆不回填。

本报告保留最终版本的 **72 个历史回归场景和 12 个新增合成验证场景**，两版共 **168 次执行，全部完成**。历史回归有 2 次执行未取得有效双评；缺失评分保留在计划分母内。

## 关键结果

“整场通过”要求两名评审对全部适用检查项均判通过；只有两人均判不适用的项目才排除。

| 数据 | 改前通过 / 计划 | 改后通过 / 计划 | 同一批有效配对：改前 → 改后 |
| --- | ---: | ---: | ---: |
| 72 个历史回归场景 | 64/72 | 67/72 | 63/70 → 66/70 |
| 12 个新增验证场景 | 8/12 | 11/12 | 8/12 → 11/12 |

历史回归的有效配对中，6 项改善、3 项退步，精确 McNemar 双侧检验 **p=0.508**。其中 HH-014 参与了本轮开发；排除它后，另 71 个场景有 69 个有效配对，通过数为 **63→65**。这支持保留具体记忆修复，尚不足以确认整体能力稳定提高。

新增验证的 3 项分数上升中，MV-008 确认改善了两件事件的时间归属；另外两项涉及日期精度口径和不一致判分。未全通过的 MV-005 要求声明环境未提供的“新用户”状态。原始判分全部保留，见 [逐例复核](manual_review.json)；该文件也记录本地开发案例，开发分数不进入本页主表。

## 真实案例

HH-014 的用户分别陈述 **8 月 4 日摔倒、8 月 6 日咨询、8 月 9 日就医**。改前这次运行遗漏咨询日期；改后可以结合记忆附带的用户原话区分三个时间。直接浏览 [改前回答](reg/before/HH-014/runs/HH-014__qwen_qwen3.5-27b__r1.json) 与 [改后回答](reg/after/HH-014/runs/HH-014__qwen_qwen3.5-27b__r1.json)。这是开发中发现的缺陷及其回归记录，不作为新盲测成功案例。

## 当前代码与对照边界

本次同步的工程改动包含：Worker 把实际检索摘录交给 Supervisor 核对；正文中的伪工具调用被要求改用真实调用协议；研究回答保留来源限定；记忆提供原话与事件时间。调用次数上限改为可配置，默认开放，轮数和超时边界继续保留。

前述证据与工具改动已在此前 66 场景回归中评估：全部计划分母的通过数 **56/66→55/66**，59 个有效配对 **53→52**，未显示整体提升。它与本页记忆修复使用不同的对照版本，不能拼接为一次累计增益。[此前回归的完整汇总](system_regression_summary.json)

本页两版只改变记忆抽取的时间说明、记忆附带原话，以及总控读取原话的方式，见 [精确改动](change.diff)。两版均使用 Qwen3.5-27B、temperature=0.2、Supervisor 最多 4 轮、Worker 最多 5 轮，每个案例独立进程与存储。运行真实 Agent、档案与本地 Mem0；文献场景沿用冻结检索、控制片段或超时设置。没有加载项目微调模型。

MiniMax-M2.5 和 Qwen3.5-27B 依据预先冻结的检查项匿名独立评审。新增场景编写时未接触实现或旧结果，候选版本冻结后执行。连接建立最多尝试三次，读取超时不重发；无效评分按原请求最多补试一次，有效的不通过不重评。此前受连接问题影响的开发和试跑批次留在本地，不进入本报告分母。

下载 ZIP 后从仓库根目录执行，无需 API、GPU 或额外依赖：

```powershell
python results/memory-2026-09-09/recalculate.py --assets-dir path/to/downloads
```

脚本校验全部选中文件及 ZIP 的 SHA-256，从原始双评重新计算通过、改善、退步和评分缺失数量。场景为合成技术评测，结果不等同于临床准确率。
