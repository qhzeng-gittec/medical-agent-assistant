# SFT 数据规模、质量与 CPT 机制实验

这组实验研究怎样把 Qwen3.5-2B 调整为能回答医学问题、同时保留通用问答能力的小模型。我们先改变问答训练数据的组成和数量，再检查提前学习医学原文是否影响后续回答。

本文涉及两种训练：**持续预训练（CPT）**让模型继续学习医学原文；**监督微调（SFT）**让模型学习“问题—推理—答案”示例。CPT→SFT 表示先学习原文，再学习如何回答问题。token 是模型处理文本的计量单位，数量不同于字数或问答条数。

## CPT 覆盖领域的复杂问答与医学迁移（2026-09-14）

在相同监督 token 预算下，加入医学关系推理问答后，CPT 模型在覆盖领域留出题上的答案满分率从 **100/500（20.0%）升至152/500（30.4%）**；不做 CPT 的模型也从 **92/500（18.4%）升至143/500（28.6%）**。这组对照支持复杂医学问答配方的效果，并在另一个一般医学题集上观察到较小的迁移收益。固定新 SFT 后，CPT 的额外收益为 **+1.8 个百分点**，方向为正，但区间包含零。

### 数据与训练设计

本轮从实际进入 CPT 的医学正文构造条件辨析、机制解释等关系问答。每个测评来源保存 CPT 训练行号、文档 ID 和 token 跨度。先保留测评来源，再生成 SFT；最终测评含500篇不同来源文档的500道题（StatPearls 406、教材94），选择时不按模型输赢筛题。来源正文有意进入 CPT，测评来源保留出 SFT，衡量的是已曝光医学知识在新问答中的调用，而不是完全未见知识的获取。[覆盖位置](relation-2026-09-14/coverage_locations.json)与[测评协议](relation-2026-09-14/evaluation_protocol.json)保留追溯信息；来源隔离及检索辅助语义检查不能保证所有相关事实均未出现在 SFT。

四组均使用已有后训练模型 Qwen3.5-2B。CPT 使用清洗后的7,584,299个输入 token、训练一轮；它不同于上文历史808万 token 的旧 CPT。SFT 使用 Attention+FFN LoRA，rank8、alpha16、dropout0.05、学习率5e-5、有效batch4、seed42，训练一个配方 epoch。

- **原题复习配方**：2,084条原医学样本和2,000条回放样本，经重复采样得到9,249条训练呈现，4,084条不同样本。
- **医学关系配方**：保留上述原医学和回放样本，加入2,535条关系问答，共6,619条不同样本。新增问答来自教材152条、PubMed 1,960条、StatPearls 423条。
- 两配方的监督 token 均为522,540，验证集均为217条。优化步数、回放曝光及总输入 token 不完全一致。这不是只改变推理复杂度、保持知识与样本多样性不变的对照。

### 覆盖领域500题：区分 SFT 提升与 CPT 增量

自由生成不提供来源正文或参考答案。使用贪心解码，总输出上限1,024 token、思考预算768 token。匿名裁判请求模型为`deepseek-v4-flash`，逐题记录返回模型标识；答案按0/1/2评分，下列正确数指答案得2分，不是包含部分分的归一化成绩。此轮没有单独汇总生成推理的正确率。

| 训练方式 | 答案满分数 | 满分率 |
| --- | ---: | ---: |
| 无 CPT → 原题复习配方 | 92/500 | 18.4% |
| CPT 一轮 → 原题复习配方 | 100/500 | 20.0% |
| 无 CPT → 医学关系配方 | 143/500 | 28.6% |
| CPT 一轮 → 医学关系配方 | 152/500 | 30.4% |

有 CPT 时，更换 SFT 配方净增加52道正确题，**+10.4个百分点，按来源文档配对bootstrap 95%区间[+5.8, +14.8]**；无 CPT 时净增加51题，**+10.2个百分点，区间[+5.4, +14.8]**。两组都支持新配方在来源留出关系题上的泛化收益。

固定医学关系 SFT，加入 CPT 修复54题、退化45题，净增加9题，即 **+1.8个百分点，文档配对区间[−2.2, +5.6]**。固定原题 SFT 时 CPT 增量为+1.6个百分点。新 SFT 对 CPT 优势的额外放大只有 **0.2个百分点，区间[−4.8, +5.2]**。因此，CPT 提供了覆盖领域内的小幅正向信号；明显的10个百分点提升主要来自 SFT 配方，尚不能据此确认复杂 SFT 特别激活了 CPT 知识。

### 一般医学题：复杂问答配方的迁移效果

复用同四个已训练模型，在600道 MedMCQA 医学题和600道通用题上另行测评，并与历史20K模型同轮比较。这批一般医学题不保证逐题被 CPT 覆盖。医学599/600题已判分，1题格式错误保留缺项，所有模型使用相同599题作比较；通用题600/600完成。答案与推理分别评分，生成预算为2,048总token／1,792思考token。它与上面的500题在题集、预算和判分协议上不同，不跨轮相减绝对分数。

| 训练方式 | 一般医学答案满分 /599 | 一般医学推理满分 /599 | 通用答案满分 /600 |
| --- | ---: | ---: | ---: |
| 无 CPT → 原题复习配方 | 311（51.92%） | 242 | 227（37.83%） |
| CPT 一轮 → 原题复习配方 | 302（50.42%） | 226 | 219（36.50%） |
| 无 CPT → 医学关系配方 | 325（54.26%） | 272 | 227（37.83%） |
| CPT 一轮 → 医学关系配方 | 325（54.26%） | 256 | 228（38.00%） |

有 CPT 时，新 SFT 比原题复习配方修复65题、退化42题，**答案净提升3.84个百分点，95%配对区间[+0.50, +7.18]**；无 CPT 时净提升2.34个百分点，区间[−1.00, +5.51]。两种初始化下的推理满分数都净增加30题（+5.01个百分点）。因此，关系问答训练的收益不仅出现在专门构造的覆盖领域题上，也出现了一般医学问答迁移信号，幅度小于领域内结果。固定新 SFT 后，两种初始化的医学答案同为325/599，未见 CPT 的额外答案收益。

这一泛化结论限定在医学问答。新配方没有显示稳定的通用提升；同轮历史综合推理20K模型的通用答案为316/600（无CPT）和304/600（旧CPT），高于新配方227/600和228/600。历史模型的通用数据比例、监督预算、LoRA范围及CPT版本不同，应作为整套方案对照。原项目409条纯文本也复测了408条，另1条保留缺项；知识、病例、上下文分开报告，不合并为总体提升。

**可支持的结论是：包含医学关系推理的新 SFT 配方，相比等监督预算的原题重复训练，在来源留出题上泛化更明显，并有一般医学迁移收益；尚未单独证明“推理越复杂，泛化越好”。** 新知识覆盖、不同样本数量和输出形式也随配方改变。CPT 的作用应报告为领域内小幅正向信号，与已确认的 SFT 配方收益分别陈述。

## SFT 数据规模与组成

实验分别比较三个因素：更换数据来源、增加不同训练示例、以及在问答训练前加入医学原文训练。以下名称指训练方案，数字指训练样本数，均不是测评题数。

| 本文名称 | 数据内容与训练方式 | 用来检查什么 |
| --- | --- | --- |
| 原项目问答集（5,418 条） | 来自 VQA-RAD 医学图像问答、MedMCQA 医学选择题和 PubMedQA 医学文献问答，含推理字段 | 项目已有的医学问答训练基线 |
| 混合问答集（5,000 条） | 4,000 条 Nemotron 通用指令、750 条 Medical-O1 医疗推理问答、250 条原项目数据 | 加入更多通用指令后，医疗与通用回答怎样变化 |
| 混合问答集（20,000 条） | 使用相同 80%/15%/5% 来源比例，包含 20,000 个不同来源 ID 的示例 | 增加不同示例的效果 |
| 重复训练对照（5,000 条） | 重复使用混合问答集的 5,000 条示例，累计呈现 20,061 条次，使答案和推理的监督 token 总量接近 20,000 条方案 | 区分增加新示例与重复学习已有示例的影响 |

通用指令包含问答、写作、编程和澄清等任务。这里的“混合”表示数据来源及比例；数据质量检查包括抽样审阅、排除已发现的问题和核对推理字段，尚未逐条认证全部答案。

七种训练方案在同一组 **600 道医疗题和 600 道通用题**上生成，共 8,400 份回答。SFT 使用 Attention LoRA、rank 8、学习率 5e-5、seed 42。两个混合问答集使用上述相同比例；每条均有非空理由字段。

医疗自动评分完成 599/600 题；缺失的同一道题对七个条件均保留缺项，没有补零或删题。通用题完成 600/600。匿名裁判实际返回模型为 DeepSeek-V4.1-Flash，答案和推理分别按 0/1/2 评分；下表列得 2 分的数量。

| 模型条件 | 医疗答案 /599 | 医疗推理 /599 | 通用答案 /600 | 通用推理 /600 |
| --- | ---: | ---: | ---: | ---: |
| 原始模型（未做本项目训练） | 246 | 174 | 249 | 237 |
| 仅医学原文训练 | 260 | 169 | 269 | 213 |
| 医学原文训练 → 原项目问答集（5,418 条） | 285 | 222 | 220 | 196 |
| 医学原文训练 → 混合问答集（5,000 条） | 292 | 223 | 321 | 287 |
| 医学原文训练 → 混合问答集（20,000 条） | 300 | 227 | 326 | 286 |
| 医学原文训练 → 重复训练对照（5,000 条） | 288 | 211 | 324 | 288 |
| 直接微调混合问答集（20,000 条） | 302 | 232 | 324 | 294 |

更换训练数据后，使用 5,000 条混合问答的模型在通用题上有 **321/600** 份答案获满分，原项目问答基线为 **220/600**，相差 **16.83 个百分点**。两者都先做了相同医学原文训练；数据来源、推理长度和监督文本量同时发生变化，因此这个差异体现整套训练数据方案的效果。

下表把其余比较对应到具体实验问题。差值表示前一方案减去后一方案的答案满分率，单位为百分点。95% 配对区间来自同一道题的结果对照；区间包含零表示这次实验仍不足以确认差异方向，完整数值见[配对统计](sft-scale/results.json)。

| 实验问题 | 比较方案 | 医疗答案差 | 通用答案差 |
| --- | --- | ---: | ---: |
| 更换数据组成有什么影响？ | 混合问答 5,000 条 − 原项目问答 5,418 条；均先做医学原文训练 | +1.17 | **+16.83** |
| 增加不同示例有什么影响？ | 混合问答 20,000 条 − 混合问答 5,000 条；均先做医学原文训练 | +1.34 | +0.83 |
| 增加新示例与重复训练有何区别？ | 混合问答 20,000 条 − 重复使用 5,000 条；监督文本量接近 | +2.00 | +0.33 |
| 提前学习医学原文有什么影响？ | 先做医学原文训练再微调 − 直接微调；均使用混合问答 20,000 条 | −0.33 | +0.33 |

第一行通用答案差的 95% 区间为 `[+12.50, +21.00]`，其余上述答案差的区间均包含零。混合数据方案为后续实验提供了通用回答表现更好的基线；样本扩量与训练顺序的结果保留为进一步选择方案的依据。

大量改善与输出终止有关：仅医学原文训练 医疗回答平均约 1,756 token，并有 210/600 条长度截断；各新 SFT 条件平均约 48–55 token，未触发医疗长度截断。事后分层支持“减少长推理循环”这一解释，但不是随机化的因果中介实验。

## 关键词 CPT 语料

本轮 CPT 使用 **8,081,489 个输入 token**，其中约 800 万为医学文本：PubMed 5,655,154、StatPearls 1,376,515、教材 968,797，另含 81,023 个通用文本 token（随医学文本一起训练，保留少量通用内容）。共选择 18,781 篇医学文档并打包为 4,505 个训练文本块（按训练长度打包后的序列）。

机械审计已经通过：全部打包 token 可回溯到原始文本，哈希、跨度、预算、EOS 和训练/验证隔离一致。但该语料是由项目问题知识驱动的关键词检索候选，**未完成逐条语义覆盖认证**；它适合诊断性 CPT 实验，不应描述成独立构建的高质量医学预训练语料。

完整 CPT 原文没有随本目录再分发。教材、Bookshelf/StatPearls 与 PubMed 摘要需要按来源逐项确认再分发条件；这里公开来源构成、选择限制、哈希和审计，使实验边界可检查。

## CPT、SFT 与输出形式

本节区分三种评分方式：候选排名比较模型给各个选项的分数；自由答案检查模型实际生成的回答；格式检查确认回答能否被程序解析以及是否正常结束。它们测的是不同环节。下述两批题和上一节的数据规模实验分别统计，不能混合计算提升。

已发布的 600 题四阶段自动测评保持不变：候选字母排名正确数为原始基座 **305/600**、CPT **325/600**、SFT **293/600**、CPT+SFT **323/600**。CPT 相对基座增加 3.33 个百分点，名义配对 95% 区间 `[+0.33, +6.50]`；单训练种子，多项比较未校正。

另一组阶段解释实验使用 596 道独立题，其中 590 道参考有效。它同时记录内容评分、候选排名、自由答案、严格格式和停止状态：

| 条件 | 内容满分 | 候选排名正确 | 可解析答案正确 | 未正常生成结束标记的数量 |
| --- | ---: | ---: | ---: | ---: |
| 基座 | 220/590 | 282/590 | 262/590 | 55 |
| CPT | 212/590 | 273/590 | 239/590 | 14 |
| SFT-only | 228/590 | 249/590 | 102/590 | 0 |
| CPT+SFT · 高学习率 | 199/590 | 248/590 | 49/590 | 0 |
| CPT+SFT · 低学习率 | 178/590 | 266/590 | 265/590 | 0 |

该结果说明候选排名、答案内容和格式遵循不能互相替代。阶段实验包含历史评分复用和多个裁判模型，只能结合保存的各评分模型分组 解读；它不覆盖 600 题纯自动指标。

低学习率控制在同一 590 题上进一步记录了训练中间检查点。低学习率最终条件相对历史 CPT+SFT 内容满分增加 4.24 个百分点，区间 `[+0.34, +8.14]`，但这是历史对照、单次训练随机种子，仍可能包含软件版本和裁判迁移影响。

## 复算与限制

```bash
python results/training-scale-cpt-2026-09-11/reproduce.py
```

脚本只复算保存结果，不重新训练或调用评分模型。本轮所有训练均为单 seed；医疗 SFT 评分缺 1 题，已给出缺失边界；通用和医疗参考均发现少量问题；SFT 规模实验没有独立改变单一数据因素；CPT 选材由项目知识驱动。以上结果不构成临床验证。
