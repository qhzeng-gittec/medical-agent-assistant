# SFT 数据规模、质量与 CPT 机制实验

本目录公开 Qwen3.5-2B 的一组 SFT 数据规模/组成对照，并补充关键词 CPT 的语料审计、四阶段测评和训练机制实验。主结果来自数百道同题比较；小样本超参和回忆探针仅作机制诊断，不计作总体效果。

## SFT 数据规模与组成

七个模型条件在同一组 **600 道医疗题和 600 道通用题**上生成，共 8,400 份回答。SFT 使用 Attention LoRA、rank 8、学习率 5e-5、seed 42。新 5k/20k 配方按预设比例混合 80% Nemotron、15% Medical-O1 和 5% 原项目数据；每条均有非空理由字段，但字段存在不等于理由已经医学核验。

医疗自动评分完成 599/600 题；缺失的同一道题对七个条件均保留缺项，没有补零或删题。通用题完成 600/600。匿名裁判实际返回模型为 DeepSeek-V4.1-Flash，答案和推理分别按 0/1/2 评分；下表列得 2 分的数量。

| 模型条件 | 医疗答案 /599 | 医疗推理 /599 | 通用答案 /600 | 通用推理 /600 |
| --- | ---: | ---: | ---: | ---: |
| 原始基座 | 246 | 174 | 249 | 237 |
| CPT-only | 260 | 169 | 269 | 213 |
| 历史 CPT+SFT · 5,418 条 | 285 | 222 | 220 | 196 |
| CPT+新 5k | 292 | 223 | 321 | 287 |
| CPT+新 20k | 300 | 227 | 326 | 286 |
| CPT+重复 5k · 匹配 20k token | 288 | 211 | 324 | 288 |
| 无 CPT+新 20k | 302 | 232 | 324 | 294 |

同题配对结果显示：

- 新 5k 相对历史配方，通用答案增加 **16.83 个百分点**，95% 区间 `[+12.50, +21.00]`；医疗答案增加 1.17 个百分点，区间跨零。
- 新 20k 相对新 5k，医疗答案只增加 1.34 个百分点、通用答案增加 0.83 个百分点，两个区间均跨零。
- 新 20k 相对 token 匹配的重复 5k，医疗答案增加 2.00 个百分点、通用答案增加 0.33 个百分点，区间均跨零。
- CPT+新 20k 相对无 CPT+新 20k，医疗答案少 0.33 个百分点、通用答案多 0.33 个百分点，区间均跨零。

因此，本轮支持采用新混合配方作为更强的通用指令基线，但**不支持“20k 必然优于 5k”或“加入 CPT 在该 SFT 后仍有明确边际收益”**。配方同时改变数据组成、理由长度与监督 token，不能把历史配方差异单独归因于样本数量。

大量改善与输出终止有关：CPT-only 医疗回答平均约 1,756 token，并有 210/600 条长度截断；各新 SFT 条件平均约 48–55 token，未触发医疗长度截断。事后分层支持“减少长推理循环”这一解释，但不是随机化的因果中介实验。

## 关键词 CPT 语料

本轮 CPT 使用 **8,081,489 个输入 token**，其中约 800 万为医学文本：PubMed 5,655,154、StatPearls 1,376,515、教材 968,797，另含 81,023 个通用 replay token。共选择 18,781 篇医学文档并打包为 4,505 个训练 block。

机械审计已经通过：全部打包 token 可回溯到原始文本，哈希、跨度、预算、EOS 和训练/验证隔离一致。但该语料是由项目问题知识驱动的关键词检索候选，**未完成逐条语义覆盖认证**；它适合诊断性 CPT 实验，不应描述成独立构建的高质量医学预训练语料。

完整 CPT 原文没有随本目录再分发。教材、Bookshelf/StatPearls 与 PubMed 摘要需要按来源逐项确认再分发条件；这里公开来源构成、选择限制、哈希和审计，使实验边界可检查。

## CPT、SFT 与输出形式

已发布的 600 题四阶段自动测评保持不变：候选字母排名正确数为原始基座 **305/600**、CPT **325/600**、SFT **293/600**、CPT+SFT **323/600**。CPT 相对基座增加 3.33 个百分点，名义配对 95% 区间 `[+0.33, +6.50]`；单训练种子，多项比较未校正。

另一组阶段解释实验使用 596 道独立题，其中 590 道参考有效。它同时记录内容评分、候选排名、自由答案、严格格式和停止状态：

| 条件 | 内容满分 | 候选排名正确 | 可解析答案正确 | 非 EOS |
| --- | ---: | ---: | ---: | ---: |
| 基座 | 220/590 | 282/590 | 262/590 | 55 |
| CPT | 212/590 | 273/590 | 239/590 | 14 |
| SFT-only | 228/590 | 249/590 | 102/590 | 0 |
| CPT+SFT · 高学习率 | 199/590 | 248/590 | 49/590 | 0 |
| CPT+SFT · 低学习率 | 178/590 | 266/590 | 265/590 | 0 |

该结果说明候选排名、答案内容和格式遵循不能互相替代。阶段实验包含历史评分复用和多个裁判模型，只能结合保存的 judge strata 解读；它不覆盖 600 题纯自动指标。

低学习率控制在同一 590 题上进一步记录了训练中间检查点。低学习率最终条件相对历史 CPT+SFT 内容满分增加 4.24 个百分点，区间 `[+0.34, +8.14]`，但这是历史对照、单 seed，仍可能包含软件版本和裁判迁移影响。

## 补充机制探针

[超参和回忆诊断](cpt/supplemental_probes.json)包含 24/12 单位的 CPT 小规模超参探针，以及 108 个裁判输入的回忆模式诊断。它们用于区分“原文续写变好”和“新问法作答变好”，样本量不足以作为总体模型提升结论，也没有触发自动扩大训练。

## 复算与限制

运行以下命令可校验公开文件 SHA-256，并复查本页主计数：

```bash
python results/training-scale-cpt-2026-09-11/reproduce.py
```

脚本只复算保存结果，不重新训练或调用评分模型。本轮所有训练均为单 seed；医疗 SFT 评分缺 1 题，已给出缺失边界；通用和医疗参考均发现少量问题；SFT 规模实验没有独立改变单一数据因素；CPT 选材由项目知识驱动。以上结果不构成临床验证。
