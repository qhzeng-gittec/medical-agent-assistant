# RAG 开发回归：关键设计对照与离线复算

> 本页保留早期 72 条开发回归。最新 [800 条查询、混合检索与最终回答完整测评](../hybrid-grounding-2026-09-08/README.md)已扩展到 1,016 篇语料，包含 BM25 / 向量 / RRF、证据不足与本地 Mem0 回答检查。

本套件公开早期 **72 条检索探针、15 个资料块、完整 Top-10 排名与 4096 维 API 向量**，展示候选数量、上下文补全和类型过滤对检索的影响。扩展后的独立测评见 [400 条查询 / 1,016 篇语料报告](../component-benchmark-2026-09-08/rag/README.md)。两套结果分别统计。

## 关键设计与结果

| 对照 | 测得的结果 | 测量条件 |
| --- | --- | --- |
| 保留多个证据候选 | 全部目标证据组覆盖 **33/40 → 39/40，增加 15 个百分点** | 相同查询、相同向量，Top-1 → Top-3，离线阈值 0.4 |
| 在查询中补全历史上下文 | 完整目标覆盖 **1/3 → 3/3** | 三对预先编写的短句 / 历史补全查询 |
| 按资料类型过滤 | 不过滤 **3/3**，指定不匹配类型 **0/3** | 三对相同查询，比较目标资料是否仍在候选范围 |

指标单位为查询。每题以 `gold_groups` 标注必要证据组，每组允许多个可替代资料块；“全部覆盖”要求每组至少命中一个块。“至少一组”只要求任意一组命中。以上是已知开发探针的检索覆盖对照；上下文改写由测试预先给定。

## 为什么最初 60 题有 40 题可回答

最初的 60 题包含 **40 条库内可回答查询、12 条库内无充分答案查询、3 条缺历史短句、3 条不匹配类型过滤查询、2 条信息不足查询**。后加 12 条近义无答案查询，共 72 条。无答案查询用于观察检索器是否返回了主题相近却缺少所问细节的资料，因此与可回答查询分开计数。

可回答集内包含上述上下文与类型过滤实验的配对对照。这是一套合成开发回归集，另外的 72 个完整 Agent 问诊场景属于独立套件。

## 怎么测的

1. 固定 [15 个资料块](corpus.jsonl)，按 NHS / CDC 页面整理中文要点摘要；保留来源、类型与版本。
2. 固定 [基础 60 题](rag_boundary.jsonl) 与 [近义无答案 12 题](rag_near_miss.jsonl)。只将 query 送入检索，标签、目标资料 ID 和独立 context 字段不进入查询。
3. 真实调用 OpenRouter `qwen/qwen3-embedding-8b`。查询前缀统一为 `Instruct: Given a medical consultation question, retrieve relevant patient guidance and clinical evidence.\nQuery: {query}`。
4. 本机归一化向量并计算余弦相似度。指定 `filter_type` 时先过滤候选类型，再取 Top-10；本套件采用精确向量排序。
5. 复用同一组排名，离线比较 K=1/3/5/10 与阈值 0/0.3/0.4/0.5/0.6/0.7/0.8，共 56 组套件 / 参数组合。分别统计可回答覆盖与无答案候选返回。

实现入口：[检索适配器](../../medix-agent-swarm/evals/campaign_rag.py)、[批量运行器](../../medix-agent-swarm/evals/holdout_rag_regression.py)。此处阈值为离线对照参数；该适配器运行时按 Top-K 返回候选。检索覆盖与最终回答质量分别评测。

## 阈值与覆盖

| K / 阈值 | 可回答：至少一组 | 可回答：全部证据组 | 一般无答案返回候选 | 近义无答案返回候选 |
| --- | ---: | ---: | ---: | ---: |
| Top-3 / 0 | 40/40 | 39/40 | 12/12 | 12/12 |
| Top-3 / 0.3 | 40/40 | 39/40 | 6/12 | 12/12 |
| Top-3 / 0.4 | 40/40 | 39/40 | 0/12 | 11/12 |
| Top-3 / 0.5 | 39/40 | 37/40 | 0/12 | 11/12 |
| Top-3 / 0.6 | 27/40 | 23/40 | 0/12 | 7/12 |

最后两列统计返回了至少一个候选的无答案查询数，数值越低表示过滤得越充分。近义无答案题要求资料中未提供的精确数字等细节，因此主题相似度与答案是否充分需要分别检查。完整分组与参数表见 [summary.json](summary.json)。

R25 按原标签要求三组资料，实际返回两组，计入 39/40；已返回的一块也包含一般照护信息。因此这里保留原始块覆盖口径。
