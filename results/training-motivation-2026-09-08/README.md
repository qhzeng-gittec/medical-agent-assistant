# 从错题诊断到 CPT 与强化学习的研究动机

**研究问题是：怎样补足并稳定调用任务所需的医学知识，以及怎样提高已有正确解法被生成和选中的概率。** 因此前者比较任务相关语料 CPT、事实 SFT，后者在正确候选与可靠奖励存在时验证 GSPO。不能将错题机械分配成“70 道由 CPT 修复、79 道由 RL 修复”。

本页于 2026-09-08 根据已完成训练的冻结诊断重新统计，用于解释研究方向并设计下一轮对照。它是阶段后的分析，不声称此前训练前已经获得这些比例，也不把动机写成已验证的训练收益。

## 1. 错题中，基础知识和应用分别是什么情况

对象为 expanded candidate 链的 Qwen3.5-2B：`reference` 是合并 CPT+SFT 后关闭 RL 适配器的参考状态，`rl` 是同一骨干开启最终 GSPO 适配器。312 道独立题包括 150 道知识题和 162 道病例题；309 道题的拆问可用，共 427 个前提，每个前提两种问法。重复问法与模型状态不增加独立题数。

评分沿用已有自动评审：0=错误，1=部分正确，2=完全正确；完整保留原始回答与评分理由，没有重新调用模型评分。最终模型 132 道答案满分，**180 道未满分=139 道完全错误+41 道部分正确**。

| 原题未满分时的拆问表现 | 题数 | 占180道未满分题 | 只看139道完全错误题 |
| --- | ---: | ---: | ---: |
| 所测前提的两种问法全部正确 | 28 | 15.6% | 17（12.2%） |
| 所测前提的两种问法全部错误 | 38 | 21.1% | 35（25.2%） |
| 部分前提两问全错，其他前提并非全错 | 32 | 17.8% | 26（18.7%） |
| 无前提两问全错，但存在部分正确或问法不一致 | 79 | 43.9% | 58（41.7%） |
| 拆问没有通过有效性检查 | 3 | 1.7% | 3（2.2%） |

分类互斥且覆盖全部错题。“全部前提”只指实验测到的前提；38 道全错题中，33 道只测了一个事实，5 道测了两个。70/180（38.9%）至少有一个前提两问都错，不代表证明模型参数中没有这些知识。

79 道部分正确/不稳定题中，**43 道至少有一个前提一问0分、一问2分**，另36道包含部分正确等情况。它说明调用对提示条件敏感，不证明原题采样中已有正确推理路径。

### 28 道前提全对，不等于 28 道纯合成推理失败

| 进一步区分 | 题数 | 占180道错题 |
| --- | ---: | ---: |
| 原题本来是直接知识问答，诊断问法答对而原题失败 | 20 | 11.1% |
| 机器初审认为前提充分且存在独立应用步骤 | 7 | 3.9% |
| 未满足上述应用题条件 | 1 | 0.6% |

7 道应用失败中，已有逐条复核认为3道存在参考答案或前提适用范围争议，保留4道较明确的应用失败（4/180=2.2%）。原评分没有被覆盖。**2.2% 是已复核保留的案例比例，不是全部错误中推理问题的真实占比**：其他题可能同时存在知识与推理错误；已测前提也未必穷尽所有必要规则。复核者为助手分析者，不是临床专家组。

例如模型在独立提问中知道相关药物禁忌，却在病例中选择错误药物；另有前提数值都正确而最终计算结果错误的案例。逐题内容、原始评分和争议理由均在 [records.jsonl](records.jsonl)。

另有 **29 道最终答案满分、解释未满分**，不在180道答案错题中。答案正确不等于完整过程可靠。

### 参考状态和任务分层

| 状态/任务 | 未满分题数 | 前提全对 | 前提全错 | 部分前提持续错 | 部分正确/问法不稳 | 无有效拆问 |

## 2. 这些证据怎样支持训练动机

| 诊断线索 | 待验证的训练假设 | 验证需要补什么 |
| --- | --- | --- |
| 基础前提持续答错 | 用准确、覆盖充分的医学原文 CPT 或事实 SFT，改善事实获取与稳定调用 | 实际训练token是否包含完整关系；多问法闭卷正确性；原本会答的事实是否退步 |
| 一问对、一问错，或只会一部分 | CPT/事实SFT可能巩固关系；RL也可能强化已有正确路径 | 在原题条件下采样，确认正确答案与正确解释是否同时存在，不能只凭改写问法答对推断 |
| 前提答对而应用失败 | 针对条件绑定、规则选择、计算与答案衔接做推理SFT；有可靠奖励与正确候选时比较RL | 核验前提充分性和评分，记录正确候选比例、奖励排序与训练后的配对变化 |

CPT 与 RL 的作用可能跨越多个类别，SFT 也可以学习事实。现有312题贪心答案为134→132，改对4、改错6，尚未证明 RL 有可靠净收益；其他采样配置的结果不能与本分母混算。研究动机是待检验的机制假设，而不是训练方案有效性的结论。

现有 [CPT 构建核查与改进方案](cpt_data_construction.md)解释关键词检索已经做到哪里、为什么尚未实现完整任务相关语料，以及下一轮如何保持可追溯性。

## 3. 复算与文件

在仓库根目录运行，不需要模型、GPU、API 或第三方Python依赖：

```bash
python results/training-motivation-2026-09-08/reproduce.py
```

程序从逐题原始分数重建类别、分母和CSV，再核对汇总与文件SHA-256。它不重新判定医学正确性。

| 文件 | 内容 |
| --- | --- |
| [records.jsonl](records.jsonl) | 312题、427个前提、两种问法；两模型原始回答、解释、评分理由与已有争议复核 |
| [question_breakdown.csv](question_breakdown.csv) | 624条模型×原题记录，包括原题分数、逐前提分数和分类 |
| [summary.json](summary.json) | 两模型、两任务、完全错误/部分正确/未满分/全题口径 |
| [provenance.json](provenance.json) | 来源、配置、统计单位和解释边界 |
| [cpt_audit.json](cpt_audit.json) | 现有训练语料、来源索引、检索策略和覆盖状态快照 |
| [retrieval_feasibility.json](retrieval_feasibility.json) | 6组手选关键词在3个本地索引中的实际检索记录；仅验证可检索，不是覆盖率或效果测评 |
| [manifest.json](manifest.json) | 本目录发布文件的SHA-256 |

数据来自公开 MedMCQA 改编的项目题目、模型生成探针和回答；来源与处理说明见[项目数据集](https://huggingface.co/datasets/starttoshow/medix-medical-sft)。项目test知识参与过CPT选材，本套件是受控知识获取与调用诊断。下一轮可继续用它观察旧错题修复，但泛化结论需要未参与选材、调参的新事实或新来源测试。
