# 模型关键测评

模型侧围绕训练配方、医学任务、强化学习和通用能力保留以下已完成测评。被测基座均为 **Qwen3.5-2B**；各实验的适配器、数据划分和生成设置独立冻结。配方 A–F、关键词 CPT 与已发布的扩展 CPT 权重链分别标识，不能串成同一次训练的连续成绩。

## 1. A–F 配方：247 道项目留出测试

比较训练数据组合和 LoRA 作用范围。150 道 MedMCQA 知识题每学科 25 道，97 道 PubMedQA 上下文题；按项目 source_id / source_group 与训练、验证隔离。含 D_half 推理消融共 **944 份回答**。这是项目自行划分的 test 集。

所有配方从同一基座独立训练：rank 8、alpha 16、dropout 0.05、学习率 5e-5、有效 batch 4、1 epoch、seed 42，视觉编码器冻结。A/B 使用 1,726 条 VQA；C/D 加入知识，共 2,919 条；E 再包含病例，共 4,653 条；F 再包含上下文，共 5,418 条。单 epoch 下训练步数也随配方大小变化。

统一 greedy、batch 4、总预算 2,048 token、思考预算 1,792 token；**gpt-5.6-sol** 匿名评答案和解释，各为 0/1/2 分。下表分数为 `50 × 平均评分`，联合分取逐题答案/解释的较低分再归一化；满分数单独列出。

| 任务 | 配方与 LoRA 范围 | 答案分 | 解释分 | 联合分 | 答案满分数 |
| --- | --- | ---: | ---: | ---: | ---: |
| 知识 | A：VQA / Attention | 66.00 | 59.00 | 59.00 | 95/150 |
| 知识 | B：VQA / Attention+FFN | 67.33 | 61.67 | 61.67 | 98/150 |
| 知识 | C：VQA+知识 / Attention | 62.33 | 56.67 | 56.33 | 89/150 |
| 知识 | D：VQA+知识 / Attention+FFN | 66.00 | 58.00 | 58.00 | 93/150 |
| 知识 | D_half：D 的 FFN 推理缩放 0.5 | 68.00 | 60.00 | 60.00 | 98/150 |
| 上下文 | E：VQA+知识+病例 / Attention+FFN | 87.63 | 78.35 | 75.77 | 79/97 |
| 上下文 | F：再包含上下文 / Attention+FFN | 87.11 | 68.56 | 65.98 | 75/97 |

D_half 复用 D 权重。六项预定答案分对照经 Holm 校正均未达到 0.05；这些结果用于比较配方，不指定跨任务“最佳模型”。[分组指标与配对区间](../../MediX-R1/reports/holdout/results.json) · [原实验配置与测试隔离记录](../../MediX-R1/reports/holdout/)

## 2. 关键词 CPT：600 道医疗选择题四阶段对照

`cpt_keyword_experiment_v1` 使用约 **808 万输入 token** 进行 CPT，再对照仅 SFT 和 CPT+SFT。CPT rank 32、学习率 5e-5、1 epoch；SFT 为 Attention LoRA rank 8、学习率 5e-5、1 epoch、5,418 条训练记录；训练 seed 42。仅 SFT 基线在配置与权重哈希核对后复用。

从官方 MedMCQA **train** 中固定抽取项目此前未使用的 600 题（抽样 seed 20260909），排除已记录训练/评测题目并检查与 CPT 语料的连续 16 词重叠。这里的留出指本项目未使用；共享医学事实及基座预训练曝光不在排除范围内。CPT 选材使用过原项目问题知识，因此这一新留出组与原项目 test 成绩分别统计。

四组使用同一提示、batch 4、关闭 thinking、greedy 最多 32 个新 token。**候选字母排名**在第一生成位置比较 A/B/C/D logits，直接按原题答案计分；另记录自由生成中可解析的字母和仅输出字母的严格格式成绩，无 LLM 评审。

| 阶段 | 候选字母排名正确 | 正确率 | 自由生成字母正确 | 严格字母格式且正确 |
| --- | ---: | ---: | ---: | ---: |
| 原始基座 | 305/600 | 50.83% | 304/600 | 304/600 |
| 仅 CPT | 325/600 | 54.17% | 324/600 | 320/600 |
| 仅 SFT | 293/600 | 48.83% | 205/600 | 45/600 |
| CPT+SFT | 323/600 | 53.83% | 310/600 | 0/600 |

候选排名：CPT 相对基座 **+3.33 个百分点**，名义配对 95% 区间 [+0.33, +6.50]；CPT+SFT 相对仅 SFT **+5.00**，[+2.00, +8.17]；CPT 后继续 SFT 为 −0.33，[−3.33, +2.67]。区间按学科分层、按题配对 bootstrap 10,000 次；单训练种子，多项检验未校正。排名与输出格式是不同测量，不能把严格格式零分解释为知识零分，也不能把排名成绩当作自由问答正确率。

## 3. VQA GSPO：93 问、16 张验证图像

以 C 配方（VQA+知识 / Attention）的 SFT 权重为起点，用 1,000 个训练提示完成 GSPO。使用 VQA-RAD 项目 validation 的 **93 问、16 张独立图像**，同图多问共同计入图像数。SFT 与 GSPO 均 greedy、最多 512 个新 token、图像长边上限 768；**gpt-5.5** 按 0/1/2 评分。

| 模型 | 归一化评分 | 答案获满分 | 部分正确 | 不正确 |
| --- | ---: | ---: | ---: | ---: |
| SFT 起点 | 60.75 | 50/93 | 13/93 | 30/93 |
| SFT+GSPO | 66.13 | 57/93 | 9/93 | 27/93 |

归一化评分增加 **5.38 分**；9 题评分改善、2 题降低、82 题同分。单种子、模型辅助评分的验证集结果；原始记录有 1 对完全相同输出得到不同评分，因此保留逐题评分，不把分数差等同于同数量的已确认医学纠错。

## 4. 扩展 CPT 权重链：知识与病例 GSPO 对照

这一组对应 2026-09-08 发布的**扩展 CPT→SFT→GSPO 权重链**，与上面的关键词 CPT、VQA GSPO 分别评测。固定项目测试中的 **150 道知识题与 162 道病例题**，共 312 题；使用相同合并参考骨干，只比较 RL 更新关闭/开启。统一 greedy、batch 4、原生预算 512 token、思考预算 384 token。

| 满分指标 | CPT+SFT 参考 | 再加 GSPO | 变化（百分点）及名义 95% 区间 |
| --- | ---: | ---: | --- |
| 答案 | 134/312 | 132/312 | −0.64 [−2.56, +1.28] |
| 解释 | 114/312 | 113/312 | −0.32 [−2.56, +2.24] |
| 答案与解释同时满分 | 104/312 | 103/312 | −0.32 [−2.56, +1.92] |

本组没有观察到明确的净提升。保留它是为了交代已发布 GSPO 权重的实际任务表现，结果不附带未经验证的训练缺陷解释。冻结评分使用 **Gemini 3.5 Flash**，同题两组按同一规则匿名评分；评分来源元数据见[评审溯源](stage_judge_provenance.json)。[完整分组汇总](../2026-09-08/training/mechanism_diagnosis_20260908/mechanisms/analysis.json) · [逐题评分](../2026-09-08/training/mechanism_diagnosis_20260908/mechanisms/states.json) · [生成协议](../2026-09-08/training/mechanism_diagnosis_20260908/plan.json)

同批另有 **91 个事实族、每族原问与改写各 1 问**的阶段探针；两种问法均满分的族数依次为：原始基座 **39/91**、CPT **38/91**、直接 SFT **45/91**、CPT+SFT **48/91**、再加 GSPO **48/91**。其中 45 族来自训练、46 族来自验证，作为阶段探针单列，不计入独立测试题数。[逐族状态与划分](../2026-09-08/training/mechanism_diagnosis_20260908/retention/family_states.json)

## 5. 通用能力：三项基准、1,500 道固定抽样题

使用原始基座与 `cpt_medical_v1` 的 CPT+SFT 权重，在 MMLU 非医学子集、ARC-Challenge、HellaSwag 各 500 题上进行零样本候选似然评测；程序按基准答案计分。

| 基准 | 原始模型 | CPT+SFT | 变化（百分点） | 配对 95% 区间 |
| --- | ---: | ---: | ---: | --- |
| MMLU · acc | 61.2% | 59.0% | −2.2 | [−5.6, +1.4] |
| ARC-Challenge · acc_norm | 44.2% | 51.2% | +7.0 | [+3.8, +10.2] |
| HellaSwag · acc_norm | 65.8% | 67.4% | +1.6 | [−0.6, +3.8] |

ARC-Challenge 经三项主检验 Holm 校正达到显著，另两项区间包含零；单训练种子、固定子集。[方法、逐题结果与离线复算](../general-benchmarks-2026-09-08/README.md)
